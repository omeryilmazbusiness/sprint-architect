NOTIFICATION QUALITY RULES
Only create notifications that are genuinely useful.
Avoid noisy spam.
Every notification must answer:
- What happened?
- Why does this user care?
- Is action required?
- Where should the user go next?

Each notification should have:
- id
- targetRole
- targetUserId or targetPatientId as appropriate
- clinicId where applicable
- type
- title
- body
- severity (INFO | WARNING | CRITICAL)
- status (UNREAD | READ)
- relatedId
- relatedType
- metadata (json/jsonb)
- createdAt
- readAt
