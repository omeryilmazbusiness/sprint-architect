Endpoint (ADMIN only):
POST /v1/admin/users/bulk-deactivate
Body (zod):
{
  targets: [{ id: string, entityType: "ADMIN" | "MANAGER" | "PATIENT" }]
}
Rules in use-case:
- Block if target id is the current admin userId -> BLOCKED_SELF
- Block if entityType=MANAGER and manager is clinics.primaryManagerUserId -> PRIMARY_MANAGER_DELETE_BLOCKED
- Otherwise set status=INACTIVE + statusReason="ADMIN_DEACTIVATED"
- For PATIENT table, set patient.status=INACTIVE (or equivalent) + statusReason
- Audit log: ADMIN_BULK_DEACTIVATE with counts + ids
Return:
{
  deactivated: number,
  blocked: [{ id, entityType, reason }]
}

Make sure list endpoint returns enough info to display (displayName, clinicName, role, status, etc.)
