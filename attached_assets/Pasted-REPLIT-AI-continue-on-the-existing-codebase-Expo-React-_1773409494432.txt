========================================================
A) BILLING RULES (MUST IMPLEMENT EXACTLY)
========================================================
1) Period format: YYYY-MM (e.g., 2026-03), timezone Europe/Istanbul.
2) Billable patient count definition (choose this default):
- Count patients with:
  - clinicId = clinic
  - arrivalDate within period month boundaries
  - status IN (APPROVED, ENDED)
- Exclude status PENDING.
(If arrivalDate missing, fallback to createdAt within month, but log a warning and document it.)

3) Invoice total:
total = patientCount * unitPrice
- unitPrice is taken from clinic.billingUnitPrice
- if null, fallback to a global default env BILLING_UNIT_PRICE_DEFAULT
- currency from clinic.currency (default EUR)

4) Invoice lifecycle:
- On LAST day of month at 09:00 local:
  - create invoices for ALL active clinics (idempotent) with status PENDING
  - set dueAt = last day 23:59 local
- At 00:00 daily:
  - any invoice still PENDING where dueAt < now becomes UNPAID
  - UNPAID triggers immediate clinic SUSPENDED and disables clinic managers + guests access
- Admin can mark invoice as PAID in invoice detail:
  - set paidAt + paidByAdminId
  - set clinic ACTIVE again and re-enable managers + guests

5) Manual “Generate invoice” must NOT exist (no UI, no endpoint). Scheduler only.
