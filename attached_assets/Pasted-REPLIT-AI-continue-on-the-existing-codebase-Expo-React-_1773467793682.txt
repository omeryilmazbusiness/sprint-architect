- VAL-001 (validation error)

- SYS-001 (unexpected error)

B) Create AppError base type
File: server/shared/errors/AppError.ts

- code (from ErrorCodes)
- httpStatus
- userMessage (safe)
- isOperational (true for expected errors)
- details (optional)
- cause (optional)

C) Request Correlation ID middleware
File: server/shared/middleware/requestId.ts
- Generates requestId per request (uuid)

D) Global Exception Handler (Express)
File: server/shared/middleware/errorHandler.ts

  “Sistem şu anda bakım sürecindedir. Lütfen daha sonra tekrar deneyin.”

- Always log structured JSON:
  { requestId, code, path, method, actorId?, stack? (only server logs) }

E) Ensure EVERY route uses consistent error throwing
- Controllers should never return random error shapes
- Usecases throw AppError with codes
- Repos map DB errors to DB-001 etc.

F) Professional validation

- Validation errors must return VAL-001 and details list.
