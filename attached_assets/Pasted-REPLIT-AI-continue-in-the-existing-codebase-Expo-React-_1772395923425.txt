========================================================
1) Create guest (Manager)
POST /v1/manager/patients
Body (zod):
{
  fullName: string,
  nationalityCode: string,
  phoneE164: string,
  arrivalDate: string (ISO date),
  departureDate: string (ISO date),
  email?: string,
  passportNo?: string,
  dateOfBirth?: string,
  preferredLanguage?: string,
  emergencyContactName?: string,
  emergencyContactPhoneE164?: string,
  arrivalAirport?: string,
  flightNumber?: string,
  notes?: string,
  requestedService?: string
}
Rules:
- departureDate must be >= arrivalDate
- status MUST be set to PENDING automatically on creation (ignore any incoming status)

2) Approve guest (Manager)
PUT /v1/manager/patients/:id/status
Body:
{ status: "APPROVED" }
Rules:
- Only manager of same clinic can approve.
- Audit log: GUEST_APPROVED

3) End guest (Manager)
PUT /v1/manager/patients/:id/status
Body:
{ status: "ENDED" }
Rules:
- Only manager of same clinic.
- Audit log: GUEST_ENDED

(If you prefer separate endpoints:)
POST /v1/manager/patients/:id/approve
POST /v1/manager/patients/:id/end
But one status endpoint is fine.

4) List guests with status filter

- status filter supports PENDING/APPROVED/ENDED
