BUSINESS RULE
A single guest key must NEVER be usable on multiple devices.

The rule must be:

1. A guest logs in with their guest key for the FIRST time
2. At that moment, a device identifier is created / collected and bound to that guest profile
3. That guest profile becomes LOCKED to that device
4. The same guest key can only be used again on that SAME device
5. If the same guest key is used from another device, login must be rejected
6. Multiple-device usage with the same guest key must be fully blocked
7. The lock must be backend-enforced, not just frontend-enforced
